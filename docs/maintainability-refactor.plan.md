## Approach

Smallest viable design that satisfies the mandate without LOC slicing:

1. **Rust: split by state ownership, not size.** `src/session.rs` → `src/session/mod.rs` facade (re-exports only, preserves every `crate::session::*` path) + 9 bounded modules in the one-way DAG below (leaf → owners → orchestrators). Rationale for the less-obvious homes: `paths.rs` owns the pure string/host helpers (`startup_nonce`, `normalize_attach_host`/`ip_is_loopback`/`is_unspecified_host`) because all lock/attach/identity users need them without upward edges; `sidecar.rs` owns `session_lang_opt` (it reads `lang.json`) and the `SpawnSpec` intent struct (the in-memory form of the CLI-owned `lang.json`/`stops.json` intent that `setup_bridge` persists — placed in the leaf so both `attach.attach_endpoint` and `spawn_lifecycle` can consume it without a cycle); `locks.rs` owns ALL guards/constants (`StartupGuard`, `EndpointGuard`, `EndpointBusy`, `STARTUP/ENDPOINT/BREAKS` stale constants stay with their guard: breaks-lock constants stay in `breaks.rs` with `BreaksGuard`, see below); `identity.rs` owns the pure/proc helpers (`unavailable`, `is_secret_flag`, `tcp_listen_inode`, `pid_holding_socket`) plus all caps; `attach.rs` owns `valid_breaks_envelope` (its sole production caller is the probe path), has NO `locks` edge (verified: `find_live_*`/legacy/probe bodies use no lock symbols), and legitimately deps `identity` at three existing production sites — `listener_present`→`port_lookup` (`src/session.rs:1746`), `display_endpoint`/`sanitize_cause`→`trunc_chars` (`src/session.rs:2497/2517`), `mask_*`→`is_secret_flag` (`src/session.rs:2581/2665/2674`); moving these callees to `paths` would violate semantic ownership (OS observation / text truncation / secret detection are identity-domain) and duplicating/inlining them is wrong, so the natural cycle-safe edge is `attach → identity` (one-way: `identity` deps `paths` only and must never reference `attach::`; topological order already holds since `identity` extracts in 1.2 before `attach` in 1.3); `breaks.rs` keeps its own `BreaksGuard`/`BREAKS_LOCK_STALE` (stops.json mutation lock — keeping it with its owner avoids a `breaks → locks` edge); the lifecycle is split from the start into `spawn_lifecycle.rs` (spawn path) and `close_status.rs` (terminal/read path) as peer modules so each follows a distinct ownership boundary (spawn path vs terminal/read path) with distinct callees and tests, and no peer cross-edge is needed (the settle/log-tail set lives entirely in `spawn_lifecycle` — its sole production caller is `spawn_in`, verified — so the peers share no helpers). Rejected alternatives: equal-size slicing; keeping one ~900-line lifecycle module (size is not the argument — the split follows the spawn-vs-terminal ownership boundary, each with distinct callees and tests); separating `spawn_in` from `close`/`status` across a shared-helper seam (rejected in favor of placing each shared helper with its sole caller set, leaving zero peer edges).
2. **Bridges: internal ownership first, physical split only on measured trigger.** Keep single-file provisioning (`include_str!` + `ensure_*`) for Python/Node/Browser as MUST; make the four state owners explicit inside each file (target registry/swap, breakpoint store+transaction, stop/wait/capture machine, framed server/terminal close) with section headers + owner docs + dispatch tables. Extract pure helpers to marked sections only. Physical multi-file layout is designed (appendix M3–M4) but SHIPPED only if a defect attributable to the boundary is measured (M2 trigger). Rejected: shared Node/Browser abstraction beyond `cdp_conn.js`/`framing.js` (worker-swap vs tab-`verifyTab`/reload are divergent domains); moving `BridgeSession` helpers across files WITHOUT the caller-held-`sessionLock` + per-method callgraph gate (see M5.2 — `st`-parameterized moves are allowed only under that gate).
3. **Tests: shared fixtures over new frameworks.** One `tests/contract/` fixture dir consumed by existing Rust/Python/JS harnesses; deterministic barriers inside existing concurrency matrices; provisioning-artifact unit tests (no daemon); live markers + canonical runner + shared isolated-`HOME` helper + failure bundle. No new runner, plugin, or dependency.
4. **Serial milestones, zero contract delta per refactor commit.** One subsystem/language at a time (shared files `src/session.rs`, `src/cli.rs`, `src/main.rs`, `SKILL.md` forbid parallel edits). Each refactor commit carries no behavior/schema change; rollback is revert-one-commit (v2 dirs disposable, no migration).

Target dependency DAG (Rust) — edges are `use` dependencies; anything not listed is FORBIDDEN (enforced by the back-edge greps in M1):

```text

  ├── spawn_lifecycle.rs (setup_bridge/spawn/spawn_in + spawn failure helpers + settle/log-tail set)
  │     deps: paths, sidecar, identity, forward, attach, locks
  ├── close_status.rs (startup_close_gate/remove_unpublished_dir/close/status/session_entry/context)
  │     deps: paths, sidecar, identity, forward, attach, locks
  ├── breaks.rs (cmd_breaks_* + stops.json mutation lock + confirmed persistence)
  │     deps: paths, sidecar, forward (via normalize_target_for_lang_opt, bridge_failure, stamp_main only — never forward_target)
  ├── attach.rs (exclusivity/endpoint/probe/legacy/diagnosis/taxonomy; NO locks edge)
  │     deps: paths, sidecar, identity (via listener_present/port_lookup, display_endpoint+sanitize_cause/trunc_chars, mask_*/is_secret_flag — existing production sites)
  ├── forward.rs (BridgeFailure/forward/roster/reload)
  │     deps: paths, sidecar, identity (via cmd_targets_in/layered_identity_or_null)
  ├── identity.rs (redact/caps/seeds/OS-probe/layered-reads)
  │     deps: paths (normalize_attach_host only)
  ├── locks.rs (startup+endpoint guards/quarantine/stale/liveness)
  │     deps: paths (startup_nonce)
  └── sidecar.rs (SCHEMA_VERSION/gate/atomic-write/session_lang_opt/SpawnSpec)
        deps: none (paths reserved)
    paths.rs (sessions_dir/check_name/check_dir_real/ports + startup_nonce + host-normalize helpers)
```
